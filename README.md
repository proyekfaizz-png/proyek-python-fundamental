**LOGIKA OPERATOR STATEMENT IF**

Dalam latihan kali ini, saya membantu teman kuliah dalam membuat sebuah program sederhana dengan 
menggunakan Operator statement IF.

Pada kasus ini sebuah perusahaan dengan tiga golongan karyawan:

1. Jika golongan A: Gaji Rp 5.000.000
2. Jika Golongan B: Gaji Rp 6.000.000
3. Jika Golongan C: Gaji Rp 9.500.000
   
dalam 3 golongan tersebut, saya menggunakan input untuk memasukan golongan karyawan, serta logika IF untuk menentukan
gaji karyawan berdasarkan golongan.

Perintah berikutnya adalah menghitung jika karyawan lembur, maka mereka dibayar perjam, dan menginput
jam lembur karyawan. Dengan ketentuan sebagai berikut:

1. Jika karyawan lembur 1 jam maka gaji lemburnya 30% dari gaji pokok
2. Jika karyawan lembur 2 jam maka gaji lemburnya 32% dari gaji pokok
3. Jika karyawan lembur 3 jam maka gaji lemburnya 34% dari gaji pokok
4. Jika karyawan lembur 4 jam maka gaji lemburnya 36% dari gaji pokok
5. Jika karyawan lembur >=5 jam maka gaji lemburnya 38% dari gaji pokok
